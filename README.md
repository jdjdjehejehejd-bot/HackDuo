# TEUM — 작은 틈을 알아보는 보안 감각

TEUM은 정보보안 기초와 화이트해커의 책임 있는 점검 방식을 처음 배우는 사람을 위한 한국어 학습 앱입니다. 새빛대학교 학생 민지와 보안 도우미 틈이가 이어지는 캠퍼스 사건을 함께 풀어요. 레슨 진입 때는 각 편의 오리지널 애니메이션풍 배경이 기기 화면을 가득 채우고, 캐릭터 동작·카메라 움직임·한국어 자막으로 짧은 이야기를 들려줍니다. 본 강좌의 30개 개념도 카툰 장면과 대화로 가르치며, 모바일 스토리 피드와 XP·레벨·연속 학습 기록, 학습자 표시 이름, 수료 강좌의 My 노트를 제공합니다.

## 에피소드 오프닝

각 편을 처음 열면 흰 카드가 아니라 Android 세로 화면 전체를 채우는 풀스크린 오프닝이 먼저 재생됩니다. 10개 편 각각에 축제 현장·기획실·네트워크실·보안 실습실 같은 전용 배경 원화를 사용하고, 새 애니메이션풍으로 그린 민지와 틈이가 전경에서 함께 움직입니다. 오프닝은 ‘무대와 인물 → 첫 사건 단서 → 이번 편의 임무’ 세 장면으로 이어지며, 장면마다 카메라 줌·패닝, 인물 위치와 조명, 하단 대사 자막이 바뀝니다.

한 장면은 약 2.4초이며 전체 길이는 약 7.2초입니다. 오프닝은 한 차례 재생된 뒤 멈추고, 사용자가 ‘수업 시작’을 눌러 본문으로 들어갑니다. 언제든 건너뛰기·일시정지·이어서 보기·다시 보기가 가능하며, `prefers-reduced-motion`을 사용하면 자동 재생 없이 정지 화면과 자막을 직접 넘겨 볼 수 있습니다.

## 학습 흐름

과정은 새빛대학교 축제 시스템에서 생긴 사건을 따라갑니다. 각 개념 수업은 세 장면으로 진행돼요. 민지가 문제를 발견하고, 틈이가 보안 원리를 대화로 설명하고, 민지가 배운 내용을 사용해 안전한 선택을 합니다. 첫 장면에는 강좌별 판단 체크포인트가 있어 선택한 경로와 피드백이 기기에 저장됩니다. 퀴즈 첫 시도 성과도 강좌별로 기록되며, 정답률이 낮은 단원은 홈 화면의 ‘맞춤 복습’으로 다시 추천됩니다. 각 화의 장소와 소품은 예매 명단, 출입 카드, 비밀 쪽지, 게시판 댓글, 수상한 이메일, 점검 범위표처럼 주제에 맞춰 달라집니다. 카툰 수업 뒤에는 적용 문제와 오답 해설로 배운 내용을 확인합니다.

학습 순서는 세 챕터로 나뉩니다. 먼저 무엇을 지켜야 하는지와 위험을 파악하고, 이어서 신원·접근 제어·암호·네트워크·웹 시스템을 설계하는 방법을 배웁니다. 마지막으로 데이터 보호와 사회공학에 대응하고, 탐지·보고·복구의 흐름을 익힙니다. 강의마다 MIT OpenCourseWare, NIST CSF 2.0, OWASP, CISA 등의 원문 학습 자료로 연결됩니다. 이 강좌는 대학 보안 기초의 핵심 내용을 초보자 수준으로 설명하며 대학 교과 과정을 대체하지는 않습니다.

레벨 3에 도달하면 실습실이 열립니다. 실습은 앱 내부에 준비된 합성 이메일, 모의 게시판, 가상 권한표만 사용합니다. 외부 사이트에 접속하거나 네트워크 요청·스캔·공격을 수행하지 않으며, 실행 가능한 취약점 악용 코드를 제공하지 않습니다.

강좌를 클리어하면 세 가지 핵심 개념과 ‘기억해 두기’ 요점이 `/my` 노트에 자동으로 추가됩니다. 노트는 기존 완료 기록을 이용하므로 이미 클리어한 강좌의 요점도 바로 표시되고, 각 노트에서 해당 강좌로 돌아가 복습할 수 있습니다. `/my`에는 첫 단서·화이트해커의 약속·안전한 실습자·필드 가이드 완주 같은 배지 컬렉션도 표시됩니다. 학습자 표시 이름과 학습 기록은 로그인이나 서버 없이 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 기록과 노트는 공유되지 않습니다.

`/teacher`에는 현재 브라우저의 학습 기록을 활용하는 교사용 데모 리포트가 있습니다. 전체 진도, 평균 정답률, 스트릭, 배지, 챕터별 진행률, 정답률이 낮은 집중 단원과 강좌별 기록을 확인할 수 있으며 CSV로 내보낼 수 있습니다. 현재는 단일 기기 데모이며, 실제 학교용 운영에서는 계정·학급·학생 데이터베이스를 연결해야 합니다.

교사용 리포트의 학급 공간에서는 학급을 만들고 초대 코드를 확인하며 학생 이름과 학년·반을 추가·삭제할 수 있습니다. 명단은 학습 기록과 분리된 `localStorage` 영역에 저장해 데모 데이터가 학습자 진행 상태를 덮어쓰지 않도록 했습니다. 실제 초대·학생별 동기화는 다음 서버 계정 단계에서 연결합니다.

학급에 학생이 등록되면 학생별 진도·정답률·스트릭·집중 단원 카드와 학급 평균 진도·정답률이 함께 표시됩니다. 현재 학생 통계 필드는 서버 동기화를 위한 데모 모델이며, 학생 계정 연결 시 해당 필드에 실제 학습 이벤트를 집계해 채우는 방식으로 확장합니다.

교사용 화면에는 학급 전체가 함께 달성하는 ‘우리 반 보안 탐정단’ 주간 챌린지도 추가되어, 현재 학습자의 완료 수와 등록 학생의 진도를 합산해 공동 목표 진행률을 보여줍니다. 개발자 모드는 활성화 직전의 강좌·실습·XP·퀴즈 기록을 스냅샷으로 보관하며, `/my`의 개발자 도구에서 **개발자 모드 해제 · 원래 상태로 복원**을 누르면 잠금과 경험치가 활성화 전 상태로 돌아갑니다.

각 강좌 오프닝은 이제 ‘지난 화의 단서 → 새로운 신호 → 현장 기록 → 임무 → 다음 화의 떡밥’ 5장면으로 이어집니다. 10개 강좌에 새빛대학교 축제 사건의 연속 단서와 다음 에피소드 클리프행어를 연결해, 단원마다 독립된 설명이 아니라 하나의 보안 미스터리를 따라가도록 구성했습니다.

오프닝 문장도 강좌 설명을 그대로 읽는 방식에서 벗어나, 민지와 틈이가 현장에서 짧게 주고받는 대화 형식으로 바꿨습니다. 각 장면에 화자의 말투, 발견한 초점, 다음 질문을 따로 두어 ‘학습 목표를 전달하는 장면’이 아니라 ‘사건을 함께 추리하는 장면’처럼 보이도록 했습니다.

첫 레슨은 민지의 독백으로 시작합니다. 새빛대 신입 민지가 보안 동아리에 들어와 축제 준비를 하던 중 동아리방의 장비를 잘못 건드리고, 동아리에서 개발 중이던 비밀 프로젝트 ‘틈이’를 깨웁니다. 놀란 민지에게 틈이가 직접 자신을 소개하고, 둘이 뒷작업을 하다 예매자 정보가 노출되는 큰 결함을 발견하면서 첫 보안 단원으로 이어집니다.

최근 스토리 리라이트에서는 화면 중앙에 표시되던 교과서식 초점 문구를 제거하고, 짧은 장면 라벨과 대사만 남겼습니다. 나머지 에피소드도 ‘개념을 설명하는 대사’ 대신 벽면 지도, 열린 화면, 급한 메일, 남겨진 로그처럼 캐릭터가 직접 마주치는 사건을 통해 개념이 드러나도록 다듬었습니다.

첫 화는 8장면으로 늘려 민지의 동아리 생활, 축제 준비, 혼자 남은 밤, 틈이와의 첫 대화, 첫 결함 발견까지 호흡을 나눴습니다. 오프닝 자동 재생 시간도 고정 2.4초가 아니라 대사 길이에 따라 약 4.5~10초로 조정되어 긴 문장이 중간에 잘리지 않습니다.

커리큘럼은 이제 `UNIT 01 무엇을 지킬까?` → `UNIT 02 어떻게 설계할까?` → `UNIT 03 어떻게 지키고 대응할까?`의 큰 주제로 나뉘고, 각 UNIT 아래에 여러 레슨 에피소드가 연결됩니다. 홈 화면에서 UNIT별 목표와 완료한 레슨 수를 확인할 수 있으며, 기존 레슨 ID와 진행 기록은 그대로 유지됩니다. 각 레슨은 축제 현장의 구체적인 사건을 오프닝 컷씬으로 보여준 뒤 개념 학습과 판단 미션으로 이어집니다.

스토리는 이제 단순한 개념 설명이 아니라 하나의 미스터리로 이어집니다. 민지가 틈이를 발견한 뒤 `guest_07` 계정, 졸업생 재호의 암호화된 경고, 무대 뒤 네트워크 장비, 평범한 댓글 속 QR 단서, 맞춤형 피싱 메일을 차례로 추적합니다. 마지막에는 재호를 성급히 범인으로 몰지 않고, 틈이의 테스트 모드가 운영 서버에 복사된 사실을 허가된 점검으로 확인합니다. 각 에피소드는 새로운 단서를 발견하고 다음 레슨의 질문을 남기는 구조입니다.

서버 계정 단계의 기반으로 `classrooms`, `classroomMembers`, `learningEvents` 테이블과 보호된 tRPC API를 추가했습니다. 인증된 교사는 자신의 학급 목록 조회·학급 생성·학생 등록·학급 개요 조회를 사용할 수 있고, 소유자가 아닌 학급은 조회하거나 수정할 수 없습니다. 배포 DB에는 `pnpm db:migrate`를 실행해 `drizzle/0001_flashy_doctor_octopus.sql`을 적용하면 됩니다. 브라우저 데모는 기존처럼 동작하며 서버 연결은 점진적으로 전환할 수 있습니다.

## 로컬 실행

```bash
pnpm install
pnpm dev:static
```

기본 개발 주소는 `http://localhost:3000`입니다. 타입 검사는 `pnpm check`, 정적 빌드는 `pnpm build:static`, 전체 테스트는 `pnpm test`로 실행합니다.

## 배포

저장소는 비공개로 유지합니다. Vercel 정적 빌드와 `/lesson/:lessonId`, `/lab`, `/my` 직접 접근을 위한 SPA rewrite 설정을 보존합니다. 공개 전환이나 자동 배포 설정 변경은 하지 않습니다.

## 주요 코드 위치

- `client/src/pages/Home.tsx`: 모바일 우선 학습 피드와 나의 기록
- `client/src/pages/LessonPage.tsx`: 편별 오프닝·개념 카툰 수업·단계형 퀴즈
- `client/src/components/LessonStoryIntro.tsx`: 편별 원화·카메라/캐릭터 동작·대사 자막으로 구성한 풀스크린 오프닝
- `client/src/components/AnimatedLesson.tsx`: 민지와 틈이가 장면을 연기하는 개념 카툰 수업·대사·재생 제어
- `client/src/data/animatedStoryboards.ts`: 9개 강좌·27개 개념의 카툰 장소·소품·대사 장면
- `client/public/anime/`: 9편 배경 원화와 애니메이션풍 인물 컷아웃(WebP)
- `client/public/cartoon/`: 개념 카툰 수업에 쓰는 민지와 틈이 이미지
- `client/src/pages/MyPage.tsx`: 완료한 강좌의 핵심 개념과 기억할 요점을 모으는 My 노트
- `client/src/pages/LabPage.tsx`: 브라우저 안에서만 작동하는 세 가지 모의 실습
- `client/src/data/lessons.ts`: 3단계 10편의 사건형 정보보안 입문·화이트해커 과정, 참고 자료와 완료 노트 변환
- `client/src/data/lessons.test.ts`: 단원 순서·진도 ID·문제와 참고 링크 회귀 테스트
- `client/src/hooks/useLearningProgress.ts`: 로컬 XP, 레벨, 스트릭 및 완료 기록
- `client/src/components/BrandMark.tsx`: TEUM 워드마크
- `client/src/index.css`: 반응형 디자인 시스템과 오프닝·개념 수업 애니메이션

새 콘텐츠도 방어·예방 중심으로 유지하고, 실습은 교육용 가상 데이터에만 한정합니다.
