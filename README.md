# TEUM — 작은 틈을 알아보는 보안 감각

TEUM은 정보보안 기초를 처음 배우는 사람을 위한 한국어 카툰 강좌 앱입니다. 새빛대학교 학생 민지와 작은 보안 도우미 틈이가 캠퍼스 사건을 연기하고, 말풍선 대화로 개념을 설명해요. 각 수업에는 재생·일시정지·다시 보기와 자막이 있어요. 모션 줄이기를 설정하면 정지된 카툰 장면을 직접 넘길 수 있습니다. 모바일 스토리 피드, XP·레벨·연속 학습 기록, 수료 강좌의 My 노트도 제공합니다.

## 학습 흐름

과정은 새빛대학교 축제 시스템에서 생긴 사건을 따라갑니다. 각 개념 수업은 세 장면으로 진행돼요. 민지가 문제를 발견하고, 틈이가 보안 원리를 대화로 설명하고, 민지가 배운 내용을 사용해 안전한 선택을 합니다. 각 화의 장소와 소품은 예매 명단, 출입 카드, 비밀 쪽지, 게시판 댓글, 수상한 이메일처럼 주제에 맞춰 달라집니다. 카툰 수업 뒤에는 적용 문제와 오답 해설로 배운 내용을 확인합니다.

학습 순서는 세 챕터로 나뉩니다. 먼저 무엇을 지켜야 하는지와 위험을 파악하고, 이어서 신원·접근 제어·암호·네트워크·웹 시스템을 설계하는 방법을 배웁니다. 마지막으로 데이터 보호와 사회공학에 대응하고, 탐지·보고·복구의 흐름을 익힙니다. 강의마다 MIT OpenCourseWare, NIST CSF 2.0, OWASP, CISA 등의 원문 학습 자료로 연결됩니다. 이 강좌는 대학 보안 기초의 핵심 내용을 초보자 수준으로 설명하며 대학 교과 과정을 대체하지는 않습니다.

레벨 3에 도달하면 실습실이 열립니다. 실습은 앱 내부에 준비된 합성 이메일, 모의 게시판, 가상 권한표만 사용합니다. 외부 사이트에 접속하거나 네트워크 요청·스캔·공격을 수행하지 않으며, 실행 가능한 취약점 악용 코드를 제공하지 않습니다.

강좌를 클리어하면 세 가지 핵심 개념과 ‘기억해 두기’ 요점이 `/my` 노트에 자동으로 추가됩니다. 노트는 기존 완료 기록을 이용하므로 이미 클리어한 강좌의 요점도 바로 표시되고, 각 노트에서 해당 강좌로 돌아가 복습할 수 있습니다. 학습 기록은 로그인이나 서버 없이 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 기록과 노트는 공유되지 않습니다.

## 로컬 실행

```bash
pnpm install
pnpm dev:static
```

기본 개발 주소는 `http://localhost:3000`입니다. 타입 검사는 `pnpm check`, 정적 빌드는 `pnpm build:static`, 전체 테스트는 `pnpm test`로 실행합니다.

## 배포

저장소는 비공개로 유지합니다. Vercel 정적 빌드와 `/lesson/:lessonId`, `/lab`, `/my` 직접 접근을 위한 SPA rewrite 설정을 보존합니다. 공개 전환이나 자동 배포 설정 변경은 하지 않습니다.

## 주요 코드 위치

- `client/src/pages/Home.tsx`: 모바일 우선 학습 피드와 나의 기록
- `client/src/pages/LessonPage.tsx`: 스토리 도입, 개념 카드, 단계형 퀴즈
- `client/src/components/AnimatedLesson.tsx`: 민지와 틈이가 장면을 연기하는 카툰 수업·대사·재생 제어
- `client/src/data/animatedStoryboards.ts`: 9개 강좌·27개 개념의 카툰 장소·소품·대사 장면
- `client/public/cartoon/`: 민지와 틈이의 카툰 캐릭터 이미지
- `client/src/pages/MyPage.tsx`: 완료한 강좌의 핵심 개념과 기억할 요점을 모으는 My 노트
- `client/src/pages/LabPage.tsx`: 브라우저 안에서만 작동하는 세 가지 모의 실습
- `client/src/data/lessons.ts`: 3단계 9편의 사건형 정보보안 입문 과정, 참고 자료와 완료 노트 변환
- `client/src/data/lessons.test.ts`: 단원 순서·진도 ID·문제와 참고 링크 회귀 테스트
- `client/src/hooks/useLearningProgress.ts`: 로컬 XP, 레벨, 스트릭 및 완료 기록
- `client/src/components/BrandMark.tsx`: TEUM 워드마크
- `client/src/index.css`: 반응형 디자인 시스템

새 콘텐츠도 방어·예방 중심으로 유지하고, 실습은 교육용 가상 데이터에만 한정합니다.
